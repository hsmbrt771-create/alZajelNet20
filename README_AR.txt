قالب شبكة الزاجل - إصدار معدل خبير شبكات

الملفات الرئيسية:
- index.html: صفحة تسجيل الدخول الرئيسية.
- status.html: صفحة مستقلة لبيانات الكرت بعد الدخول، وبها فقط بيانات الكرت + الاستراحة + مشاهدة المباريات + تسجيل الخروج.
- prices.html: أسعار الكروت.
- ads.html: الإعلانات.
- lounge.html: الاستراحة.
- matches.html: مشاهدة المباريات.
- sales-points.html: صفحة داخلية لنقاط البيع، غير مضافة في القوائم، وتقرأ البيانات من قاعدة محلية داخل assets/js/sales-db.js.
- assets/js/sales-db.js: قاعدة بيانات نقاط البيع المحلية.
- assets/js/app.js: منطق الواجهة، الإشعارات، الكاروسيل، الدخول التجريبي، وحالة الاتصال.

ملاحظات مهمة للـ MikroTik Hotspot:
1) في app.js اجعل CONFIG.demoMode = false عند التركيب الحقيقي.
2) نموذج الدخول في index.html مضبوط على:
   action="$(link-login-only)"
   hidden dst="status.html"
   hidden popup="true"
3) عند نجاح الدخول، يرسل الراوتر المستخدم إلى status.html لعرض بيانات الكرت.
4) إذا كانت الكروت عندك تستخدم نفس الرقم كاسم مستخدم وكلمة مرور، الجافاسكربت ينسخ رقم الكرت إلى حقل password تلقائيًا.
5) صفحة status.html تستخدم متغيرات MikroTik مثل:
   $(username), $(uptime), $(session-time-left), $(bytes-in-nice), $(bytes-out-nice), $(ip), $(mac), $(link-logout)
6) سعر الكرت واسم الباقة لا يخرجان دائمًا من MikroTik تلقائيًا. الأفضل ربطها حسب Profile أو وضعها يدويًا عبر window.MK_PRICE و window.MK_PACKAGE أو تعديل الخريطة في app.js.
7) صفحات الهوتسبوت الثابتة لا تملك قاعدة بيانات حقيقية داخل الراوتر. لذلك تم تنفيذ قاعدة نقاط البيع كملف JavaScript محلي: assets/js/sales-db.js. يمكن تعديلها من الملفات ثم رفعها للراوتر.
8) صفحة نقاط البيع لا تظهر في القوائم. افتحها يدويًا من الراوتر/المتصفح باسم:
   sales-points.html

أكواد التجربة في وضع demoMode=true:
- 0000: رقم غير صحيح.
- 1111: صلاحية منتهية.
- 2222: الوقت انتهى.
- 3333: البيانات انتهت.
- 4444: الكرت مستخدم على جهاز آخر.
- 5555: السيرفر مشغول.
- 6666: مشكلة اتصال.
- 9999: محاولات كثيرة.
- أي رقم آخر يعتبر صحيحًا وينقلك إلى status.html?demo=1.

تركيب مقترح:
- ارفع محتويات المجلد كاملة إلى MikroTik Hotspot Files.
- تأكد أن أسماء الملفات كما هي.
- اختبر الدخول بكرت حقيقي.
- إذا لم يتم التحويل إلى status.html، تأكد من hidden input باسم dst وقيمة status.html.
