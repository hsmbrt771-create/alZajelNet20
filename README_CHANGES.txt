تعديلات النسخة المحسنة:
- تحسين ملف CSS وترتيبه بالكامل داخل assets/css/style.css بدون أكواد CSS داخل الصفحات.
- إضافة زر تبديل وضع النهار / الوضع الليلي مع حفظ اختيار المستخدم في localStorage.
- إصلاح ظهور تنبيهات الخطأ في الجوال لتظهر أعلى الشاشة بدل الأسفل.
- تحسين ظهور كرت الوكيل في الشاشات الصغيرة وعدم إخفائه.
- تحسين تجاوب الهيدر، الكروت، صفحة تسجيل الدخول، صفحة الحالة، وصفحات الخدمات.
- إصلاح خطأ محتمل في الساعة العربية عند فتح صفحات لا تحتوي على عنصر الوقت.
- تحسين صفحة الخدمات وترتيب أكواد HTML المكسورة.
- إضافة favicon و theme-color لجميع الصفحات.

ملاحظة مهمة:
إذا أردت تشغيل القالب على MikroTik الحقيقي بدل التجربة المحلية، افتح assets/js/app.js واجعل:
demoMode: false

- إصلاح تخزين آخر 3 كروت مستخدمة: كان كود الحفظ موجودًا بدون استدعاء عند تسجيل الدخول وبدون تهيئة عرض القائمة، لذلك لم تظهر الكروت المحفوظة. تم ربط الحفظ بتسجيل الدخول وإضافة عرض/حذف/مسح الكروت.
- إضافة تنسيق كامل ومتجاوب لقسم «آخر 3 كروت مستخدمة» مع إمكانية الضغط على الكرت لإعادة تعبئته في حقل الدخول.
